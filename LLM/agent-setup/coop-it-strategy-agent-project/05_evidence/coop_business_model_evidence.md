## Digital Business Model-tolkning

### Value proposition

Coop App og medlemsprogrammet lover i praksis flere verdityper:

- økonomisk verdi gjennom bonus, personlige tilbud, medlemsfordeler og FordelsKonto,
- bekvemmelighet gjennom Scan & Betal, digitale kvitteringer, handleliste og betalingsfunksjoner,
- relevans gjennom personaliserte tilbud, lokal butikkkommunikasjon og kjøpsdata,
- identitet/relasjon gjennom medlemskap, medeierskap, Samvirke og lokal tilhørighet,
- ansvarlighet gjennom klimaavtrykk, økologisk andel og Änglamark-/produktkrav.

Dette er en bred value proposition. Det indikerer strategisk bredde, men også risiko for uklarhet på tvers av kjeder.

### Value creation

Verdien kan skapes for flere parter:

- kunder får tilbud, enklere butikkreise, bonus, oversikt og underholdning,
- butikker kan få raskere checkout, høyere trafikk fra premier/kampanjer og mer relevant kommunikasjon,
- Coop-kjeder kan bruke felles medlems-/appinfrastruktur til ulike kundeløfter,
- leverandører kan få eksponering gjennom kampanjer, branded prizes og mulig retail media,
- Lobyco kan skape verdi ved å gjøre Coop-teknologi gjenbrukbar som OEM-/lojalitetsplattform.

### Value capture

Mulige value capture-mekanismer er:

- butikktrafikk,
- økt kurvstørrelse,
- høyere handlefrekvens,
- lavere friksjon i butikk,
- supplier-funded campaigns,
- retail media,
- bedre kundeinnsikt og segmentering,
- sterkere retention i medlemsbasen.

Men: offentlige kilder dokumenterer ikke netto lønnsomhet, marginbidrag eller kausal effekt. Dette må derfor behandles som mulige mekanismer, ikke etablerte resultater.

### Key resources / capabilities

Relevante ressurser og kapabiliteter:

- fysisk butikknettverk,
- medlemsbase over 2 millioner,
- Coop App og appdata,
- Lobyco som digital kapabilitet / mulig modular producer,
- private labels,
- Coop Trading og leverandørnettverk,
- kjedeporteføljen,
- lokal governance og medlemsrelasjon.

### Channels

Kanaler:

- fysiske butikker som hovedkanal,
- Coop App,
- medlemskommunikasjon,
- kjedenes egne sider og tilbudsaviser,
- retail-media-/kampanjeflater,
- tidligere coop.dk / Coop.dk MAD, som nå er lukket og derfor bør brukes som historisk kontrast.

### Governance / KPI-problem

Den sentrale styringsutfordringen er at sterke app-metrics ikke automatisk sier om appen skaper verdi for Coop. Før senere anbefalinger bør prosjektet etterspørre eller formulere behov for KPI-er som:

- appbrukeres inkrementelle butikkbesøk,
- inkrementell kurvverdi og margin, ikke bare omsetning,
- effekt per kjede,
- aktiveringsrate og faktisk innløsning av personlige tilbud,
- kostnad per appfunksjon/kampanje,
- supplier-funded campaign margin etter kostnader,
- kundetillit og opplevd relevans,
- Lobyco ekstern inntekt, kostnad og strategisk avhengighet.
