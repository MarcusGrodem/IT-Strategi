# Final Quality Check

This checklist is based on the written assignment slide and informal quality criteria for exam papers.

## Exam Assignment Fit

| Criterion | Status | Notes |
|---|---|---|
| Paper is 5-25 pages | Not started | Check at drafting stage |
| Case concerns a company where digital opportunities are central | In progress | Coop App/Lobyco focus |
| Case is strategically interesting | In progress | Financial pressure, store dependency, digital capability, competition |
| Uses 1-2 self-selected course perspectives | Open | User must choose |
| Gives strategic advice to an actor in the case | Open | User must choose actor |

## Informal Quality Criteria

| Criterion | Status | Required check |
|---|---|---|
| Learning objectives | Not checked | Shows mastery of course learning objectives |
| Independent voice | Not checked | Does not simply repeat Lobyco/supplier claims |
| Relevant course material | Open | Uses relevant concepts/frameworks |
| Clear focus | Open | Avoids broad digital transformation essay |
| One overall convincing argument | Open | Must be explicit |
| Critical approach | In progress | Source criticism built into workflow |
| Application, discussion and reflection | Open | Theory must be applied, not only explained |
| Meta communication | Open | Sections should explain what happens next and why |

## Argument Structure Rule

Each analytical section should follow:

```text
Claim -> Reasoning -> Empirical observations -> Strategic implication
```

## Current Main Risks

- Theory overload.
- Too broad scope.
- Weak causality between app use and profitability.
- Overuse of marketing sources.
- Unclear advised actor.
- Generic recommendations.
