## 6. Strategic Situation Analysis

Purpose:

This is the analytical core. Recommendations must follow from this section.

Recommended subsections:

### 6.1 Financial Pressure And Investment Scarcity

Claim:

Implication:

### 6.2 Bricks-And-Mortar As Strategic Core

Claim:

Coop App should be analysed as a store-linked digital asset.

Implication:

App value should be measured by support for physical-store economics and customer relevance.

### 6.3 App Reach Versus Strategic Value

Claim:

App reach matters, but reach is not proof of strategic or financial success.

Implication:

Martin should challenge engagement metrics and request business-model fit metrics.

### 6.4 Chain Differences And The "Go Deep" Option

Claim:

Coop's chains may need different app value propositions.

Implication:

### 6.5 Lobyco As Capability, Distraction Or Governance Object

Claim:

Lobyco should not be treated as automatically keep/sell; it should be governed as a Coop-first capability unless stronger evidence supports divestment.

Implication:

Lobyco must be addressed in the recommendations, even if not as a standalone recommendation.

### 6.6 Retail Media, Gamification And Supplier-Funded Value

Claim:

Retail media/gamification may create value capture, but current evidence is marketing-heavy.

Implication:

Treat these as testable mechanisms, not proof of success.

### 6.7 Competitor Fit

Claim:

Competitors show that digital tools create value when they fit business model and customer promise.

Implication:

Coop should not copy competitors but should ensure app logic fits each chain and store model.

## 8. Strategic Recommendations

Purpose:

Present five recommendations in continuation of the analysis.

### Recommendation 1: Redefine Coop App Success Around Business-Model Fit And Store-Level Value

Include:

- KPI hierarchy.
- Lobyco as Coop-first capability under same governance logic.
- Retail media as possible value capture with trust/KPI guardrails.

Theory:

- DVC: digital outputs vs deeper value.
- Digital Business Model: value capture/governance.

### Recommendation 2: Develop Chain-Specific App Value Propositions Within One Governed Coop Platform

Include:

- Do not necessarily build separate apps.
- Use shared platform with chain-specific modules.
- 365discount, Brugsen, SuperBrugsen/Kvickly may need different app relevance.

Theory:

- DVC: relevance.
- Digital Business Model: differentiated value propositions and channels.

### Recommendation 3: Review And Redesign Gamification/Engagement Features Unless They Show Customer Or Store Value

Include:

- Do not claim gamification fails.
- Treat it as a testable feature group.
- Keep only if it supports customer relevance, supplier-funded value after costs or store behaviour.

Theory:

- DVC: experiences and outputs.
- Digital Business Model: value capture.

### Recommendation 4: Use Coop App To Strengthen Member Relationships While Separating Loyalty From Profitability

Include:

- Coop's member identity and trust.
- Distinguish relationship value from incremental profitability.
- Avoid selection bias in app-user claims.

Theory:

- DVC: relationships.
- Digital Business Model: relationship value must translate into value capture.

### Recommendation 5: Pilot Chain-Level App Initiatives Before Scaling Major New Investments

Include:

- Distinguish from Recommendation 2.
- This is implementation/testing, not strategy design.
- Define metrics before pilot launch.

Theory:

- DVC: test relevance/experience.
- Digital Business Model: test value proposition and value capture.
