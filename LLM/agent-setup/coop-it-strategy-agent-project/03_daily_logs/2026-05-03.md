## 4A. Important Workflow Clarification

The user does not want to choose executive, theory or strategic position yet.

The purpose of the option banks is to preserve alternatives so they can be compared later. The remaining agents should now be used to create a stronger basis for choice:

- Evidence Extractor should collect facts and claims relevant to each option.
- Source Critic should classify reliability and bias so weak evidence is not overused.
- Competitor & Market Agent should show how competitor evidence affects strategic positions.
- Theory Application Agent should explain what each theory option reveals and what it misses.
- Recommendation Agent should later generate recommendations only after the argument is better informed.
- Red Team Agent should challenge whether any option creates a stronger or weaker exam paper.

No option should be locked until the user explicitly chooses.
