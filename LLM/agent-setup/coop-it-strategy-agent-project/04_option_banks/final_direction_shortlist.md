# Foreløpig Retningsshortlist

Dette dokumentet lager en kritisk shortlist over de mest lovende retningene for oppgaven. Det er ikke en finalrapport, det låser ingen caseperson, teori eller strategisk stance, og det skriver ikke endelige anbefalinger.

Formålet er å snevre inn valgrommet før senere beslutning. Alle vurderinger bygger på eksisterende analyse- og evidensfiler, særlig `06_analysis/strategic_situation_analysis.md`, `04_option_banks/decision_preparation.md`, `05_evidence/source_verification_packet.md`, `05_evidence/evidence_verification_plan.md`, `06_analysis/theory_to_evidence_matrix.md`, `06_analysis/digital_business_model_analysis.md` og `06_analysis/competitor_analysis.md`.

## 1. Martin Hasgard Olesen + Hybrid Governance

| Felt | Vurdering |
|---|---|
| Caseperson | Martin Hasgard Olesen, direktør for Kommunikation, Marketing og Digital. |
| Mulig hovedargument | Coop bør ikke velge mellom ukritisk appstyrking og digital nedskalering nå. Coop bør heller styre Coop App og Lobyco som en kundevendt digital kapasitet med krav til butikkøkonomi, kjedespesifikk verdi, tillit og KPI-dokumentasjon. |
| Strategisk stance | Hybrid governance: behold og videreutvikle App/Lobyco selektivt, men bind investering til outcome-KPI-er og kjedebehov. |
| Best passende 1-2 teoriperspektiver | DVC Framework + Digital Business Model. Plattform/ecosystem kan bare brukes som svak støtte hvis retail media blir relevant. |
| Hvilke deler av teorien som bør brukes | DVC: experiences, relationships, relevance, digital infrastructure og outputs. Digital Business Model: value proposition, value creation, value capture, key resources/capabilities, channels og governance/KPI-er. |
| Sterkeste evidens | Coop er fysisk butikkbasert og finansielt presset; Coop App har dokumentert reach som marketing claim fra Lobyco; Lobyco fremstår som mulig digital kapabilitet; konkurrentanalysen støtter digital fit fremfor "mer app"; kildekritikken viser behov for styring fremfor bastante appkonklusjoner. |
| Svakeste evidens | Appbruker-frequency, Playable-effekt, retail media-verdi og Lobyco business model er ikke uavhengig dokumentert. Intern KPI-evidens for kurv, margin, trafikk og retention mangler. |
| Kildekritiske problemer | Retningen bruker Lobyco, Playable og Shortcut som viktige kilder, men alle er kommersielt interesserte. Appreach må brukes som reach, ikke lønnsomhetsbevis. Retail media må omtales som mulig verdilogikk, ikke dokumentert inntektsmotor. |
| Hva retningen kan gi av 2-5 anbefalinger senere | Senere anbefalinger kan handle om KPI-gates for appinvestering, kjedespesifikk styringsmodell, Lobyco-mandat, retail-media guardrails og selektiv forenkling av appfunksjoner. Dette er mulige anbefalingsområder, ikke valgte anbefalinger. |
| Eksamensrisiko | Medium. Retningen treffer oppgaven godt, men kan høres som kompromiss hvis den ikke gir tydelige beslutningskriterier. Risikoen er også at oppgaven blir for marketing-/digitalorientert hvis butikkøkonomi og investeringstrade-offs ikke styrer analysen. |
| Hva som må verifiseres før retningen kan låses | Lobyco-eierskap, økonomi, ekstern kundebase og strategisk avhengighet; Coop App KPI-er; definisjon og dato for 1,8m brukere, 25 % reach og 880k MAU; om kjedespesifikk appmodulering er teknisk/økonomisk realistisk; 232m loss vs. -215m EBIT. |
| Samlet vurdering | Høy. Dette er foreløpig den mest balanserte retningen fordi den gjør kildeusikkerheten til en del av strategien i stedet for et problem som må skjules. |

## 2. Michael Tilsted + 365discount / Go Deep

| Felt | Vurdering |
|---|---|
| Caseperson | Michael Tilsted, direktør for 365discount. |
| Mulig hovedargument | 365discount bør ikke nødvendigvis arve en bred Coop App-logikk. Appverdien for discount bør vurderes gjennom pris, enkelhet, spareopplevelse og butikkutility, eventuelt som en kjedespesifikk modul eller tydelig discount-modus. |
| Strategisk stance | Go deep by chain, men helst som modulær/kjedespesifikk appverdi heller enn automatisk separat app. |
| Best passende 1-2 teoriperspektiver | DVC + Porter/positioning. DVC + Digital Business Model kan brukes hvis value capture og governance må være mer sentralt. |
| Hvilke deler av teorien som bør brukes | DVC: relevance, relationships, experiences og digital outputs for discount-kunder. Porter/positioning: fit, trade-offs, activity system og konkurranseposisjon. Digital Business Model-støtte: value proposition og value capture per kjede. |
| Sterkeste evidens | Casen spør eksplisitt om "go deep"; 365discount er Coops lavprisformat; konkurrentanalysen peker mot Lidl Plus, REMA Scan Selv og discount-/savings-/simplicity-logikk; digital verdi virker sterkest når den passer forretningsmodell og kundeløfte. |
| Svakeste evidens | Det mangler direkte data om 365discount-kunders appbruk, prispersepsjon, friksjon i dagens Coop App og økonomisk effekt av discount-spesifikke digitale funksjoner. Konkurrentevidensen viser fit, ikke kausal app-effekt. |
| Kildekritiske problemer | Lidl- og REMA-kilder må skilles mellom offisielle funksjonssider, promoterte claims, sekundære finansdatabaser og omstridte markedsandelsclaims. Det må ikke skrives at Lidl/REMA beviser at 365discount trenger egen app. |
| Hva retningen kan gi av 2-5 anbefalinger senere | Senere anbefalinger kan handle om discount-modus, spare-/pris-KPI-er, færre engagement-funksjoner for 365discount, test av kjedespesifikke moduler og governance som hindrer at fellesappen svekker discountløftet. |
| Eksamensrisiko | Medium. Retningen er skarp og case-nær, men kan bli for smal eller for konkurrentdrevet. Den må fortsatt forholde seg til Coop App/Lobyco som konsernressurs, ikke bare 365discount sin brukerflate. |
| Hva som må verifiseres før retningen kan låses | 365discounts eksakte kundeløfte og kjedeposisjon; appfunksjoner i Coop App som faktisk brukes av 365discount-kunder; Lidl Plus og REMA originalkilder; kostnad og kompleksitet ved separat app, modul eller discount-modus; om Lobyco kan støtte modulering uten å øke kompleksitet for mye. |
| Samlet vurdering | Høy. Dette er den tydeligste chain-specific retningen og kan gi et eksamensmessig skarpt svar på "go deep"-spørsmålet, men bare hvis 365discount-evidensen styrkes. |

## 3. Thor Skov Jørgensen + Investeringsstyring

| Felt | Vurdering |
|---|---|
| Caseperson | Thor Skov Jørgensen, adm. direktør / CEO. |
| Mulig hovedargument | Coop bør behandle Coop App og Lobyco som portefølje- og investeringsvalg under økonomisk knapphet. Spørsmålet er ikke bare om appen er populær, men hvilke digitale investeringer som fortjener kapital, ledelsesoppmerksomhet og organisatorisk kompleksitet. |
| Strategisk stance | Investeringsstyring / portfolio discipline. Kan inneholde scenarier for redusere, styrke, styre eller vurdere Lobyco, men bør ikke låse salg/afhændelse uten mer evidens. |
| Best passende 1-2 teoriperspektiver | Digital Business Model + Implementation, alternativt DVC + Digital Business Model hvis kundeappverdien skal være tydeligere. |
| Hvilke deler av teorien som bør brukes | Digital Business Model: value creation, value capture, key resources, channels og governance. Implementation: alignment, stage-gates, operational fit og KPI-er. DVC som støtte: digital outputs versus outcomes. |
| Sterkeste evidens | Coop har dokumentert stor fysisk butikkøkonomi, men fortsatt negativ EBIT i 2025; coop.dk MAD og Coop.dk-webshop er lukket; casen spør direkte om redusere, selge, styrke eller gå dypt; appreach er relevant, men ikke lønnsomhetsbevis. |
| Svakeste evidens | Lobyco-kostnader, inntekter, salgsverdi, ekstern kundebase og strategisk unikhet er ikke dokumentert. Uten disse dataene blir salg/afhændelse svært spekulativt. |
| Kildekritiske problemer | Finansielle tall må holdes regnskapsmessig presist: 232m loss og -215m EBIT må ikke blandes. Lobyco- og appclaims fra leverandør-/subsidiary-kilder kan ikke brukes som investeringsbevis. |
| Hva retningen kan gi av 2-5 anbefalinger senere | Senere anbefalinger kan handle om porteføljeprioritering, stage-gates, investeringskriterier, Lobyco-scenarioanalyse, krav til app-KPI-er og prioritering mellom butikkjerne og digital kapabilitet. |
| Eksamensrisiko | Medium/Høy. CEO-vinkelen eier hele diskusjonen, men oppgaven kan bli for bred og miste den kundevendte app-/Lobyco-kjernen. Salg av Lobyco må holdes som scenario, ikke konklusjon, hvis evidensen ikke styrkes. |
| Hva som må verifiseres før retningen kan låses | Presise Coop 2025-tall og case-tall; Lobyco-eierskap, økonomi, kostnader, investeringer og ekstern verdi; appens dokumenterte butikk-/margin-KPI-er; alternative investeringsbehov i butikk, pris, logistikk eller kjedeutvikling. |
| Samlet vurdering | Medium/Høy. Retningen er strategisk sterk og eksamensrelevant, men den krever hardere finansiell og organisatorisk evidens enn prosjektet har nå. |

## 4. Rikke Krause + SuperBrugsen/Kvickly Chain-Specific App Value

| Felt | Vurdering |
|---|---|
| Caseperson | Rikke Krause, direktør for SuperBrugsen og Kvickly. |
| Mulig hovedargument | Coop App og Lobyco bør vurderes etter om de styrker SuperBrugsen og Kvickly sitt butikkbaserte kundeløfte: inspirasjon, handleopplevelse, lojalitet, butikktrafikk og relevante tilbud. |
| Strategisk stance | Chain-specific app value: felles infrastruktur, men sterkere moduler og KPI-er for SuperBrugsen/Kvickly. |
| Best passende 1-2 teoriperspektiver | DVC + Digital Business Model. DVC + Porter/positioning kan være aktuelt hvis kjedeposisjonering blir hovedgrepet. |
| Hvilke deler av teorien som bør brukes | DVC: experiences, relationships, relevance og customer journey. Digital Business Model: value proposition, channels, value creation og value capture i fysisk butikk. Porter-støtte: fit og differentiation for større butikk-/supermarkedskjeder. |
| Sterkeste evidens | Coop er fysisk butikkbasert; appen har funksjoner som tilbud, bonus, Scan & Betal, handleliste, kvitteringer og spill; konkurrentanalysen peker mot Salling store utility og Dagrofa/MENY chain identity; kjedeforskjeller er dokumentert som relevant caseproblem. |
| Svakeste evidens | Det mangler SuperBrugsen-/Kvickly-spesifikke data om kundebehov, appbruk, butikktrafikk, kurv, margin og hvilke appfunksjoner som faktisk styrker disse kjedene. |
| Kildekritiske problemer | Dagrofa/MENY og Loyalty Group/BrancheIndex kan ikke brukes som hardt bevis på lojalitet eller økonomisk effekt. Appfunksjoner fra Coop-sider dokumenterer funksjon, ikke verdi. |
| Hva retningen kan gi av 2-5 anbefalinger senere | Senere anbefalinger kan handle om inspirasjons- og handleplanleggingsmoduler, butikktrafikk-KPI-er, kobling mellom personlige tilbud og fersk-/måltidskategorier, lokal butikkkommunikasjon og differensiert appopplevelse for SuperBrugsen/Kvickly. |
| Eksamensrisiko | Medium. Retningen kan bli god hvis oppgaven skal være kunde- og butikkorientert, men den kan underbehandle Lobyco-eierskap, 365discount og konsernets kapitalallokering. |
| Hva som må verifiseres før retningen kan låses | Eksakte kundeløfter for SuperBrugsen og Kvickly; appfunksjoner og bruk per kjede; evidens for at inspirasjon, tilbud eller Scan & Betal påvirker butikktrafikk, kurv eller lojalitet; om Lobyco kan levere kjedespesifikke moduler. |
| Samlet vurdering | Medium. Retningen er relevant og mindre spekulativ enn Torben-vinkelen, men foreløpig mindre strategisk skarp enn Martin, Michael og Thor. |

## 5. Torben B. Andersen + Brugsen / Local-Member App Value

| Felt | Vurdering |
|---|---|
| Caseperson | Torben B. Andersen, direktør for Brugsen. |
| Mulig hovedargument | Coop App bør vurderes som en mulig støtte for Brugsen sin lokale, medlemsorienterte og butikkforankrede identitet, ikke bare som en sentralisert kampanje- og tilbudskanal. |
| Strategisk stance | Local-member app value: selektiv kjedetilpasning som styrker lokal relevans, medlemsrelasjon og butikkfellesskap. |
| Best passende 1-2 teoriperspektiver | DVC + Porter/positioning. DVC only kan fungere hvis oppgaven holdes svært fokusert, men risikerer å underanalysere økonomi og Lobyco. |
| Hvilke deler av teorien som bør brukes | DVC: relationships, relevance, experiences og digital infrastructure. Porter/positioning: fit, differentiation og activity-system rundt lokal butikkidentitet. |
| Sterkeste evidens | Coop har mer enn 2 millioner medlemmer/medeiere som del av identiteten; Coop er fysisk butikkbasert; Brugsen kan teoretisk kobles til lokal relevans og medlemskommunikasjon; konkurrentevidens fra MENY/Dagrofa antyder at kjedeidentitet kan være viktig. |
| Svakeste evidens | Det finnes foreløpig lite direkte Brugsen-spesifikk app-, kunde-, medlems- eller lokalbutikk-evidens. Retningen er mer konseptuelt interessant enn empirisk sterk nå. |
| Kildekritiske problemer | Medlems- og lokalidentitetsclaims kommer primært fra Coop-selvpresentasjon og må ikke forveksles med dokumentert kundeadferd. MENY/BrancheIndex må ikke brukes som direkte støtte for Brugsen uten caveat. |
| Hva retningen kan gi av 2-5 anbefalinger senere | Senere anbefalinger kan handle om lokale appflater, medlemsdialog, lokal butikkkommunikasjon, forenklet sentral kampanjelogikk og KPI-er for lokal relevans eller medlemsaktivering. |
| Eksamensrisiko | Høy. Retningen kan bli særpreget, men den kan bli for smal, for normativ og for lite knyttet til den forventede direksjonsdiskusjonen om investering, Lobyco og apputvikling. |
| Hva som må verifiseres før retningen kan låses | Brugsen sitt eksakte kundeløfte; medlemmenes faktiske bruk av app/lokal kommunikasjon; om lokale butikker har digitalt handlingsrom; om Lobyco/Coop App kan støtte lokal modulering uten for høy kompleksitet; om lokal medlemsverdi kan kobles til butikkøkonomi. |
| Samlet vurdering | Lav/Medium. Retningen bør ikke være førstevalg nå, men kan holdes som en mulig støttevinkel dersom oppgaven senere vektlegger Coop-identitet og medlemskap. |

## Retninger Som Bør Droppes Eller Holdes Svake

| Retning/vinkel | Bør droppes eller holdes svak? | Hvorfor |
|---|---|---|
| Ren "styrk appinvesteringen fordi Coop App har mange brukere" | Holdes svak | Appreach er relevant, men dokumenterer ikke lønnsomhet, margin, retention eller konkurransefortrinn. Lobyco-tall er marketing claims og bør ikke bære hovedargumentet alene. |
| Ren "selg/afhænd Lobyco" | Holdes svak / droppes som hovedretning nå | Casen gjør salg relevant, men prosjektet mangler Lobyco-økonomi, salgsverdi, ekstern kundebase, kostnader og strategisk alternativverdi. Som hovedargument blir dette for spekulativt nå. |
| Ren "reduser appinvestering" | Holdes svak | Finansielt press støtter investeringsdisiplin, men Coop har også en stor digital kundekontakt og mulig Lobyco-kapabilitet. Et rent kutt kan virke anti-digitalt og lite nyansert i et IT-strategifag. |
| Retail media / plattform som hovedargument | Holdes svak | Playable, Lobyco og supplier-funded campaign claims er interessante, men hovedsakelig leverandør-/marketingkilder. Coop kan ikke omtales som moden plattform uten sterkere evidens. |
| Gamification som hovedvinkel | Droppes | Playable-tall kan være støtteclaims, men de dokumenterer ikke nettoøkonomi eller strategisk verdi. For smalt og for leverandørdrevet. |
| Shortcut/app-utviklingshistorikk som hovedvinkel | Droppes | Shortcut er nyttig for historikk og capability-fortelling, men ikke en nøytral kilde til strategisk suksess. Vinkelen svarer heller ikke godt nok på casevalgene. |
| Torben/local-member som hovedretning uten mer evidens | Holdes svak | Vinkelen er interessant, men evidensgrunnlaget er foreløpig smalt. Den bør eventuelt brukes som underargument i en bredere kjedespesifikk eller hybrid governance-retning. |
| Nemlig/online grocery som hovedkontrast | Droppes som hovedretning | Nemlig kan brukes til å nyansere coop.dk-lukking og online grocery-økonomi, men oppgaven handler om Coop App/Lobyco, ikke om ny e-commerce-satsing. |

## Foreløpig Beste 2-3 Retninger

Dette er en foreløpig rangering for videre arbeid. Den låser ikke valg.

### 1. Martin Hasgard Olesen + Hybrid Governance

Dette er foreløpig sterkest fordi retningen treffer Coop App, Lobyco, lojalitet, retail media, kjedestyring og kildekritikk direkte. Den passer godt med DVC + Digital Business Model og kan gjøre evidensusikkerheten til et analytisk poeng: Coop bør styre videre digital investering etter dokumenterbar butikk- og kjedeverdi.

For å bli låst må retningen få tydeligere KPI-logikk og bedre verifisering av Lobyco/app-claims.

### 2. Michael Tilsted + 365discount / Go Deep

Dette er den skarpeste chain-specific retningen. Den svarer direkte på case-spørsmålet om å "go deep" og kan bruke konkurrentevidens om discount, savings og simplicity på en tydelig måte. Den kan gi en mer distinkt oppgave enn en bred governance-vinkel.

For å bli låst må retningen få bedre 365discount-spesifikk evidens og unngå å bli en Lidl/REMA-sammenligning.

### 3. Thor Skov Jørgensen + Investeringsstyring

Dette er den mest konsernstrategiske retningen og den som best eier den samlede direksjonsdiskusjonen. Den er særlig sterk hvis brukeren vil skrive om kapitalallokering, opportunity cost og Lobyco som porteføljevalg.

For å bli låst må retningen få bedre finansielt og organisatorisk grunnlag, særlig rundt Lobyco-kostnader, verdi, eierskap og alternativverdi. Uten dette bør Thor-vinkelen brukes som investeringsstyring, ikke som salg/afhændelse-konklusjon.

## Arbeidskonklusjon

Den mest robuste videre beslutningspakken er å sammenligne:

1. Martin/hybrid governance som bred, kildekritisk app-/Lobyco-styring.
2. Michael/go-deep som skarp kjede- og discountvinkel.
3. Thor/investeringsstyring som konsernstrategisk porteføljevinkel.

Rikke bør holdes som en mulig fjerde retning hvis oppgaven ønskes mer kundeopplevelses- og butikkorientert. Torben bør holdes svak inntil mer Brugsen-spesifikk evidens finnes.
